# Q//Horizon 2026: a 4-qubit quantum classifier vs. classical models

**Question:** can a small variational quantum classifier (VQC) predict whether a California district's median house value is above or below the median as well as standard classical models, and what changes its results?

Everything runs on a noise-free simulator (PennyLane `default.qubit`) with 4 qubits.

## Repository layout

| File | What it does |
|---|---|
| `Classical.ipynb` | Loads the data, builds 5 train/test splits, trains 4 classical models, writes `splits/` and `results/classical.json` |
| `Quantum.ipynb` | Trains the VQC on the same 5 splits, writes `results/quantum.json`, and compares quantum vs. classical (tables and plots) |
| `Ablation.ipynb` | Changes circuit depth (1 to 4 layers) and removes entanglement, writes `results/ablation.json` |
| `vqc.py` | The circuit and training code, shared by both quantum notebooks |
| `results/` | All outputs: JSON results, `summary.md` / `summary.csv`, `comparison.png`, `ablation.png`, `circuit.png`, `environment.txt` (exact package versions of the last run) |
| `splits/` | The saved train/test splits, so both model families see identical data |

## How to reproduce

```bash
pip install -r requirements.txt
jupyter notebook
```

Then open each notebook and choose **Kernel -> Restart & Run All**, in this order:

1. `Classical.ipynb` (needs internet once, to download the dataset through scikit-learn)
2. `Quantum.ipynb` (a few minutes)
3. `Ablation.ipynb` (a few minutes)

Everything is seeded (seeds 0 to 4) and the simulator is exact, so reruns give the same accuracies.

## Data

California Housing from scikit-learn (`fetch_california_housing`; 1990 US census, Pace & Barry 1997). Task: classify whether `MedHouseVal` is above the median. Four features: `MedInc`, `Latitude`, `Longitude`, `HouseAge`. For each seed we draw 800 rows (stratified), split 600 train / 200 test (stratified), and map every feature to [0, pi] with a `QuantileTransformer` fitted on the training rows only.

## Models

- **Classical:** logistic regression, RBF-SVM (grid-searched with 5-fold CV on the training set), small MLP (37 parameters), large MLP (1,249 parameters).
- **Quantum (VQC):** angle encoding (one `RY` per feature on its own qubit), 3 `StronglyEntanglingLayers` (36 parameters), read-out of the Pauli-Z expectation on qubit 0, square loss, full-batch Adam. Details and design reasons are in `Quantum.ipynb`.

## Results

See `results/summary.md` (mean +/- std test accuracy over the 5 splits, train accuracy, fit time, parameter count), `results/comparison.png` and `results/ablation.png`. All are regenerated by the notebooks.
